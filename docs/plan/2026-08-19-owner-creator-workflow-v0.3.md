# 老板创作流水线 v0.3 施工计划

日期：2026-08-19
状态：实施中

## 目标

把当前“从模糊想法开始”的任务 A 改为“建立老板创作资料”，并交付一条可操作的垂直切片：

```text
老板资料与实拍素材
  → 选择固定模板或输入视频意图
  → AI 生成并填充可编辑脚本结构
  → 保留版本 / 换一版
  → 逐镜匹配实拍素材
  → 批量生成缺失镜头提案
  → 冻结镜头清单
  → 一键创建拼合提案
```

## 本轮范围

- 重写稳定路径下的 PRD，补充用户资料字段、动态追问、脚本模板、版本、素材状态和拼合闸门。
- 新增产品架构 JSON 与单文件 HTML，区分已实现、提案、假设和风险。
- 新增老板资料、脚本结构、分镜素材状态的纯前端领域模型与单元测试。
- 在现有桌面视觉系统内新增一条可交互工作流；示例生成、匹配和拼合必须明确标为本地演示，不调用付费 Provider。
- 保留现有研究、素材库、AI 剪辑、复盘和桌面 IPC 路径。

## 不动项

- 不改 Electron preload allowlist，不新增文件系统或密钥权限。
- 不调用真实图片/视频生成服务，不产生费用。
- 不实现真实视频编码或发布；本轮“一键拼合”产出可审阅的拼合提案状态。
- 不删除现有创作工作台、已有项目数据或已有测试。
- 不凭资料生成未经用户确认的经历、资历、经营数字、疗效或收益承诺。

## 主要风险与控制

| 风险 | 控制 |
|---|---|
| 首次建档太长导致放弃 | 最小必填 + 模板动态追问；显示“为什么要问”；允许稍后补充 |
| 年龄、声音、肖像等资料被过度采集 | 年龄段替代生日；真人素材逐条授权；敏感字段默认不收 |
| 一键换版覆盖用户修改 | 每次生成新版本；当前版本可回退；按钮明确写“换一版” |
| 素材误匹配 | 显示匹配理由和置信状态；允许替换/清空；不直接进入渲染 |
| 生成镜头带来费用或错误事实 | 本轮仅演示；真实接入时生成前展示数量、成本和授权确认 |
| UI 看似完整但后端未上线 | 所有模拟能力显示“交互原型/本地演示”；PRD 将真实 Provider 和渲染列为后续实现 |

## 回滚

- 新流程以独立 renderer 组件和纯函数模块接入；回滚时移除新导航入口即可恢复原有首页和创作项目工作台。
- 不迁移数据库、不改现有 IPC 合同，因而无需数据回滚。
- PRD 和架构文件是新增/修订文档，可按 Git 提交整体回退。

## 验收门

1. 用户可填写最小资料，且缺少必填项时不能进入脚本生成。
2. 用户可上传多个视频文件元数据，并看到用途/授权提示。
3. 固定模板与自定义意图都能生成至少一版个性化脚本结构。
4. “换一版”创建不同版本，不覆盖上一版。
5. 每个分镜显示 `已匹配 / 待生成 / 已生成` 之一，并可解释来源。
6. 批量生成只处理缺失镜头；拼合按钮仅在所有镜头就绪后可用。
7. 桌面和窄窗口均无页面级横向溢出，键盘焦点和错误状态可见。
8. `npm run typecheck`、相关单元测试、`npm run build` 和浏览器用户路径通过。
